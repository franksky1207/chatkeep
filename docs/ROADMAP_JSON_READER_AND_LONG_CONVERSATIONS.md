## 一、動機與已驗證事實

使用者以 ChatGPT 官方匯出的 `conversations-000.json`～`003.json` 在 GitHub Pages 本機解析、搜尋、選出《高中導師遊戲》1～9，並成功下載 9 個獨立的原始 JSON 檔。**原始 JSON 下載不經 Render**，實際觀察 Render Bandwidth 幾乎未變；但 JSON 的原始結構不適合直接閱讀。

改用 Word 轉換，同 9 段真實長對話測試 **0/9 成功**：
- 1、3、4、6、7、9：`CONVERSION_TIMEOUT`，後端 `json_api.py` 目前有 45 秒單批轉換時限。
- 2、5、8：`SELECTED_SOURCE_LIMIT`，現行單段選取來源上限約 16 MB。
- Windows 顯示 9 個 JSON 檔約為：1=8,766 KB、2=18,073 KB、3=7,955 KB、4=10,177 KB、5=20,245 KB、6=14,605 KB、7=11,188 KB、8=20,917 KB、9=7,117 KB。
- 來源大小未超限不代表能在 45 秒轉換完成；不要單純調高限制或宣稱大型 Word 已通過。
- Render 免費服務需注意記憶體、轉檔處理期限及流量。保留既有正式版，另規劃改善。

## 二、下一版候選功能：JSON 本機閱讀版（優先研究）

目標：把選取的官方備份對話 JSON **在瀏覽器本機**轉成可閱讀且可複製的內容，無須先轉 Word、不呼叫 Render、不上傳私人備份，讓一般人不必閱讀 JSON 代碼。

### 使用者需求
1. 在 ChatKeep 中對選取對話提供「閱讀版」入口，區分「下載原始 JSON」與「轉 Word」。
2. 保留原始訊息順序、使用者／ChatGPT 發言者、段落、標題、清單、表格、程式碼、引用等可支援的語義；不改寫、不摘要、不憑空補內容。
3. **可直接選取、複製**：支援網頁閱讀區 Ctrl+A/Ctrl+C 的合理體驗，更重要的是專用「複製整段對話」功能，**只複製正文，不夾雜網站按鈕／導覽**。若支援大量內容，一定要考慮瀏覽器記憶體與剪貼簿極限；超過安全閾值時提供分段複製／匯出，不假稱已複製完整。
4. 提供可本機下載的 **HTML 閱讀版**（可離線開啟）及 **TXT／Markdown**（實際格式待評估），並且維持原始 JSON 的獨立下載。
5. 複製到 Word／Google 文件可望保留部分基本格式，但**不保證完全保留網頁排版**；純文字目標只保留文字。
6. 巨型對話需採用分頁、虛擬化顯示或分卷匯出等策略，避免一次渲染數萬訊息而凍結。虛擬化後 Ctrl+A 可能只包含載入部分，因此應由資料模型產生完整文字複製或分批匯出，不把畫面上的可見 DOM 當完整來源。
7. 需要釐清原始 JSON 可能含分支、非可見紀錄和工具資訊；**閱讀版的主線選取與涵蓋範圍要透明標示**，不得將「閱讀版」冒充官方 JSON 的全部資料。
8. 以安全方式處理 HTML、Markdown、連結及未知節點；不執行備份內嵌程式／腳本，不引入 XSS；下載 HTML 必須是安全的靜態閱讀文件。
9. 保持手機／電腦支援；可加入閱讀版搜尋、導覽等，但先完成最小可用流程，避免功能蔓延。

### 預期用途
- JSON：提供 ChatGPT 或研究工具分析，最大程度保留原始結構。
- HTML：人類閱讀、選取、複製、離線收藏，盡量保留基本排版。
- TXT／Markdown：簡單複製、搜尋、提供其他 AI 使用。
- DOCX：正式排版與文件收藏，仍由 Render 處理。

## 三、Word 超長對話的獨立改善方向

保留為另一個待規劃議題，不與閱讀版混成必須同時完成的大工程：
- 找出超過 45 秒的主要處理成本（JSON 正規化、內容轉換、Word 產出、壓縮、驗證）。
- 研究安全的更小批次與多卷 DOCX／ZIP，降低每批轉換負擔。
- 評估 16 MB 來源限制和已存在的 chunk 傳輸設計，不可無條件調高上限。
- 嚴格保留完整性報告、原始順序、錯誤透明度與資料隱私。
- 用小型合成資料作自動化測試，真實私人備份只在使用者本機實測，不上傳 GitHub。

## 四、下一段對話接手原則

1. **先讀本文件和現有 GitHub 程式**，確認前端 JSON 解析／原始 JSON 下載可否直接重用，不要重新發明同一套功能。
2. 先討論「JSON 閱讀版」的輸出樣貌、複製方式、超長對話記憶體及分卷策略。
3. 使用者未明確要求開始實作前，不建立 PR、不改程式碼、不部署。
4. 使用者偏好以 Chat + GitHub 處理較小的修改；若涉及大幅跨模組重構才考慮 Codex。
5. v1.1.0 已正式發布；測試失敗的九段 Word 長對話**不代表 JSON 篩選或下載失敗**。
