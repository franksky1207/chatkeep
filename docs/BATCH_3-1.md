# 第 3-1 批｜Word 專業閱讀版型（施工紀錄）

## 本批內容
- `word_layout.py`：共用繁體中文閱讀字型、A4 預設版面邊距、段落行距、Word 標題階層、頁腳頁碼欄位。
- 正式 `word_export.build_docx()` 呼叫共用版型，同時相容 `rich=False` 的逐字保存模式及 `rich=True` 的元件閱讀版型。
- `rich_word.py`：一般文字段落內保留來源換行，降低無意義逐行分段；程式碼採等寬字體與適當段距；資訊卡／泡泡／表格維持可編輯原生元件。
- 表格儲存格禁用同一列的跨頁切割（`w:cantSplit`）；標題和下一段維持連續；不強制每則對話換頁。
- `tests/test_word_layout.py`：已提交頁碼、標題、方框、600 則訊息等合成測試。

## 工作界線
本批**不修改擷取器及正規化資料模型**，也不承諾所有內容的畫面完全等同 ChatGPT。複雜嵌套 DIL、LINE 語義判定、圖片實體和公式仍需後續集中驗收。專業閱讀版型以不刪改原文、可編輯、文字流暢為優先。

## 驗收安排
依使用者要求，多批施工、**完整功能／視覺／長文測試集中於第 5-1 批**。本批只做程式施工與靜態結構檢查，不宣稱新增測試通過，不啟動 Actions。第 5-1 批需測：中文顯示、Word/手機開啟、頁碼、目錄導覽、跨頁方框／表格、數百至千則訊息、文字與順序完整性、記憶體與效能，並修正失敗項。
