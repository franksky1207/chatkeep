ChatKeep｜對話收藏

將 ChatGPT 分享連結轉成 Word，或從 JSON 備份整理、閱讀與收藏對話。

開發設定

貼上公開分享連結

  1. 貼上連結
  2. 開始轉換
  3. 查看報告並下載

僅適用於 ChatGPT 的公開分享連結。私人對話不能直接由網址擷取，請改用「JSON 檔轉 Word／HTML」模式。

格式範例：https://chatgpt.com/share/00000000-0000-0000-0000-000000000000

轉換可能需要一些時間；超長對話可能分卷下載。遇到問題時會直接顯示原因。

從 JSON 檔案找出想收藏的對話

  1. 選擇備份並建立索引
  2. 搜尋、勾選對話
  3. 轉換、查看報告並下載

整份備份只在你的瀏覽器本機解析。只有按下「轉換選取對話為 Word」後，明確選取對話的轉換所需資料才會傳送到 Render；未選取的對話不會傳送。

了解資料傳送與隱私範圍
  • 小型對話可能傳送完整的單一已選官方 JSON，其中可能包含 metadata（附加資料）與非當前分支資料。
  • 大型對話在本機建立衍生有效訊息序列，分段傳送，避免傳送不必要的 metadata 與非當前分支內容。
  • Render 轉換時會暫時在記憶體處理選取內容；本程式不永久儲存對話本文，也不將私人內容寫入一般日誌。
  • 原始 JSON 下載只在本機擷取，不會因此送出對話。它保留原始結構與可能的其他分支，不是 Word，請妥善保存。

這些說明是目前程式的資料處理範圍，不是對瀏覽器、網路或服務平台的絕對隱私保證。

1．選擇 JSON 檔案

例如 conversations-000.json、conversations-001.json 或官方匯出 ZIP。數百 MB 備份建議使用電腦的一般瀏覽模式；手機可能因記憶體或空間不足而停止。

ZIP 本機暫存與支援限制

備份分塊背景掃描，不會一次解析整包 JSON。ZIP 只解壓對話 JSON 至瀏覽器的網站儲存空間（OPFS），不會因此上傳。清除索引或取消掃描時會刪除暫存；關閉分頁時會嘗試清理，異常關閉可能殘留，請清除此網站的儲存空間。

無痕模式的 ZIP 暫存可能占用大量記憶體。ZIP64、加密或異常高壓縮比例不支援；遇到限制請在電腦解壓，再分批選取 JSON。

2．搜尋與選取對話

日期與系列編號篩選

日期依 UTC 日曆計算，包含起訖當天。系列編號只辨識系列名稱後的阿拉伯數字或中文數字；各篩選條件同時套用。

3．已選清單與轉換

勾選對話後，可直接使用下方按鈕；不必捲到清單底部。

原始 JSON 下載保留選取對話的原始資料（包含其他分支與非可見紀錄），僅在瀏覽器本機處理。

本機 HTML 閱讀版

JSON 備份在瀏覽器本機解析；公開分享連結由 Render 取得正文。含格式複製及 HTML 下載在本機完成，網站無法確認 Word 的貼上結果。

每次複製後先貼入 Word，再按下一批；不會自動覆寫剪貼簿。

Word 轉換進度與下載

每段對話依序處理，通過完整性驗證後才提供下載。大型對話會顯示目前批次；Render 轉換中沒有可用的內部百分比。

容量、下載與取消說明

成果暫存最多 32 MB。容量不足會暫停，請逐段下載，確認瀏覽器已保存後再「清除暫存 Word」，即可繼續下一段。清除暫存 Word 只清除本頁尚保留的 DOCX／ZIP，不影響已下載的檔案，完整性報告仍保留。網站無法偵測檔案是否真的保存至磁碟，也不會自動將全部對話合併下載。

每段選取來源最多 16 MB、每次上傳 2 MB、最多 16 批／16 卷及 16 MB 最終成果。大型單則訊息可能超限，不能任意裁切。

取消會停止後續批次與目前連線，清除未完成的轉換資料，已完成成果保留。瀏覽器取消不保證同步 Render 子程序立即停止，仍受既有最長 45 秒期限控制。
