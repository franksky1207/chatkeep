ChatKeep｜官方備份對話擷取

從 ChatGPT 官方匯出的 JSON 中，找出想保存的對話。所有備份檔均在你的瀏覽器本機讀取，不上傳 GitHub 或 Render。

1．選擇官方 JSON 檔

支援官方 JSON 對話陣列；ZIP 請先在電腦解壓縮。大型備份採逐檔處理，不會一次解析所有檔案，但單一 JSON 若過大仍可能受瀏覽器記憶體限制，建議使用電腦。

2．搜尋並選取對話

3．下載 JSON，再前往 Word 轉換

下載的是原始單一對話 JSON，不是 Word。每個檔案包含該對話完整的官方資料結構（包括可能的其他分支及非可見記錄），請妥善保存。

前往 Render ChatKeep ↗

重要：目前 Render 只支援「分享連結 → Word」，尚不接受這裡擷取的 JSON。上述連結只是開啟 ChatKeep，必須等下一階段新增 JSON 匯入 API 後才能一鍵轉換。
