ChatKeep｜對話收藏

將重要的 ChatGPT 對話收藏成可編輯的 Word，或先從官方備份中找出想保存的對話。

轉換服務設定

請填入已支援 v2 API 的本機或核准測試服務。正式 https://chatkeep.onrender.com 仍為 v1.0.0，新路由尚未部署；此開發版不預設連線正式服務。設定僅保留在本分頁記憶體。

A．公開分享連結轉 Word

公開分享頁由 Render 擷取，完成後可於本頁下載 DOCX 或 ZIP。既有 v1.0.0 服務仍可獨立使用。

B．官方備份轉 Word

JSON／ZIP 備份只在瀏覽器本機解析與搜尋。按下「轉換選取對話為 Word」才會將明確選取的單一對話或其必要衍生批次傳送至 Render；不傳送整份備份或未選取的對話。

1．選擇官方 JSON／ZIP 備份

備份以分塊方式在本機背景掃描，不會一次載入整包 JSON。ZIP 僅解壓對話 JSON，暫存於此瀏覽器的網站儲存空間；清除清單或取消時會刪除。若分頁異常關閉而殘留暫存，可清除此網站的儲存空間。數百 MB 備份建議使用電腦的一般瀏覽模式；無痕模式的 ZIP 暫存可能占用大量記憶體。手機可能因記憶體或空間不足而停止。ZIP64、加密或異常高壓縮比例不支援，請先在電腦解壓並分批選取 JSON。

2．搜尋並選取對話

日期依 UTC 日曆計算，包含起訖當天。系列編號僅在系列名稱後面辨識阿拉伯數字或中文數字，避免誤選相似標題。

3．轉換 Word 或下載原始 JSON

原始 JSON 下載獨立保留官方對話物件的原始 UTF-8 位元組（包含其他分支與非可見記錄），不是 Word。Word 轉換會驗證目前分支，只輸出支援的可見訊息。

4．轉換狀態與完整性報告

依序處理各段；每段最多 16 MB 原始來源、每次上傳 2 MB、16 批／16 卷、最終 16 MB。成果暫存總預算 32 MB，容量不足會暫停，請逐段下載並釋放後繼續。本頁不保存私人對話至雲端或永久儲存。

瀏覽器取消會停止後續批次與目前 fetch，但不保證同步 Render 子程序即時停止；仍受既有後端最長 45 秒期限控制。已完成段落保留，取消中的段落不提供下載。
