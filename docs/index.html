ChatKeep｜對話收藏

將重要的 ChatGPT 對話收藏成可編輯的 Word，或先從官方備份中找出想保存的對話。

A．公開分享連結轉 Word

已可使用：透過 Render 將 ChatGPT 公開分享連結轉換為 Word（DOCX）。

前往分享連結轉 Word

目前開啟既有穩定版 Render 網站，避免影響原本的轉換功能。

B．官方備份擷取對話 JSON

選擇 ChatGPT 官方匯出的 JSON 或 ZIP，在你的瀏覽器本機建立索引、搜尋與下載指定對話。備份不會上傳 GitHub 或 Render。 尚未開放 JSON 轉 Word；後續版本才會傳送你確認選取的對話至 Render。

1．選擇官方 JSON／ZIP 備份

備份以分塊方式在本機背景掃描，不會一次載入整包 JSON。ZIP 僅解壓對話 JSON，暫存於此瀏覽器的網站儲存空間；清除清單或取消時會刪除。若分頁異常關閉而殘留暫存，可清除此網站的儲存空間。數百 MB 備份建議使用電腦的一般瀏覽模式；無痕模式的 ZIP 暫存可能占用大量記憶體。手機可能因記憶體或空間不足而停止。ZIP64、加密或異常高壓縮比例不支援，請先在電腦解壓並分批選取 JSON。

2．搜尋並選取對話

日期依 UTC 日曆計算，包含起訖當天。系列編號僅在系列名稱後面辨識阿拉伯數字或中文數字，避免誤選相似標題。

3．下載 JSON，再前往 Word 轉換

下載的是從已驗證來源直接擷取原始 UTF-8 位元組的單一對話 JSON，不是 Word。每個檔案保留該對話物件原始位元組（ZIP 為解壓後的 JSON 範圍），包含完整官方資料結構（包括可能的其他分支及非可見記錄），請妥善保存。

前往分享連結轉 Word

重要：目前 Render 只支援「分享連結 → Word」，尚不接受這裡擷取的 JSON。上述連結只是開啟現有轉換網站，必須等下一階段新增 JSON 匯入 API 後才能一鍵轉換。
