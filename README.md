# ChatKeep｜對話收藏

**讓每段對話，都能好好保存。**

ChatKeep 是公開開發的工具，目標是將 **ChatGPT 公開分享連結** 轉換為**完整、乾淨、易讀、可編輯的 Word（.docx）**。支援台灣繁體中文、手機直向與桌機。

## 核心原則

- **完整原文，不摘要、不改寫**：保持使用者與助理對話次序、文字與原有標點。
- **先驗證擷取，再做排版**：解析後確認訊息數、角色、順序，缺漏需明確提示。
- **清掉介面編碼，不丟失內容**：例如 `<box>`、`<row>`；LINE 聊天的文字需重新結構化，不能刪掉整個區塊。
- **閱讀型 Word**：區分使用者與 ChatGPT、場景時間、LINE 訊息，保留標題、表格、清單、超連結、必要的真實程式碼；提供頁碼與導覽。
- **圖片不憑空補造**：只有可取得的真實圖片才嵌入，否則提出警告。
- **原始資料與閱讀版分離**：可選擇下載 JSON 供備份或稽核。
- **公開程式碼，不公開私人對話**：測試資料採合成或去識別化範例，避免記錄原文、避免無必要留存。

## 開發狀態

目前仍在規劃及解析器驗證階段，**尚未確認 ChatKeep 自行擷取超長分享對話成功**。已用第三方匯出的 JSON 觀察訊息資料結構，但那不等於獨立擷取成功。

## 分批開發

1. 分享連結解析器、角色／順序還原、完整性報告
2. UI 元件與 Markdown 語義轉換
3. Word 閱讀型排版及超長文件效能
4. 網頁前端與後端部署
5. 安全性、故障注入及跨裝置整合驗收

詳見 [開發規劃](docs/PLAN.md)。

## 技術限制

GitHub Pages 只能部署靜態前端，若無法在瀏覽器直接跨來源讀取 ChatGPT 分享頁面，需要獨立後端／Serverless API。ChatGPT 網頁格式可能變更，解析器應具備格式偵測、測試及明確失敗報告。引用開源程式碼時須先核對授權。
